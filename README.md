ข้อมูลโปรไฟล์ส่วนตัว 

ชื่อ นายอรุณรัตน์ ประเสริฐสังข์ คณะเทคโนโลยีสารสนเทศ สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏร้อยเอ็ด

 ข้อมูลเบื้องต้น
- ชื่อ-นามสกุล: นายอรุณรัตน์ ประเสริฐสังข์ (Arunrat Prasertsang)
- สาขาวิชา: วิทยาการคอมพิวเตอร์ (Computer Science)
- ทักษะและความสนใจ:

ข้อดี
- ชอบการแก้ปัญหาอย่างเป็นระบบและคิดแบบเป็นขั้นตอน (Step-by-step)
- มีความตั้งใจและมุ่งมั่นในการเรียนรู้เทคโนโลยีหรือเครื่องมือใหม่ๆ 

ข้อเสีย
- บางครั้งจดจ่อกับการเขียนโปรแกรมหรือแก้ปัญหามากเกินไปจนลืมแบ่งเวลาพักผ่อน
- กำลังพยายามพัฒนาทักษะการสื่อสารภาษาอังกฤษให้มีความมั่นใจและคล่องแคล่วมากยิ่งขึ้น

คติประจำตัว
> "ความสำเร็จเกิดจากการเรียนรู้และลงมือทำอย่างเป็นขั้นตอน"

ความประทับใจ 1 เรื่อง
**ความสำเร็จในการสร้างระบบฐานข้อมูลของตัวเอง**
เรื่องที่ประทับใจคือตอนที่ผมสามารถออกแบบและสร้างฐานข้อมูลที่ชื่อว่า `personal_property_db` ด้วย MySQL และเชื่อมต่อการทำงานกับหน้าเว็บ PHP ได้สำเร็จด้วยตัวเอง การได้นำความรู้เรื่องโครงสร้างข้อมูล การออกแบบฐานข้อมูล และการเขียนโค้ดมาประกอบร่างกันจนเป็นระบบที่ทำงานได้จริง ทำให้ผมภูมิใจและมีแรงบันดาลใจในการพัฒนาระบบอื่นๆ ต่อไป
